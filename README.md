# Arunkumar Packirisamy — Portfolio

A responsive personal portfolio built with Next.js 14, TypeScript, Tailwind CSS, Framer Motion and Lucide icons.

## Run locally

1. Install Node.js 18.17 or later.
2. Extract this project.
3. Open a terminal in the project folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open http://localhost:3000

## Before publishing

Update these placeholders in `app/page.tsx`:
- `your.email@example.com` — replace with your public contact email.
- GitHub URL — replace with your GitHub profile.
- Experience dates, titles and descriptions — verify against your CV.
- Project descriptions — confirm what can be shared publicly.

Update `app/layout.tsx`:
- Replace `https://example.vercel.app` with your deployed portfolio URL.

Add your resume:
- Place your PDF at `public/resume.pdf`.

The supplied profile illustration is already included as `public/profile.jpeg`.

## Deploy free on Vercel

1. Create a GitHub repository and push this project.
2. Sign in at https://vercel.com using GitHub.
3. Import the repository and click Deploy.
4. Vercel will provide a `*.vercel.app` URL.

No backend or environment variables are required for this starter.
